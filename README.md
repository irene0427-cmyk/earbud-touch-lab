# Earbud Lab · 이어버드 인터랙션 테스트

이어버드 중앙의 원형 터치패널로 음악과 통화 조작을 체험하는 웹 프로토타입입니다. 이미지·음악·스타일·스크립트가 `index.html` 한 파일에 포함되어 있어 별도 빌드 없이 실행됩니다.

## 사용 방법

사이트에서 **꺼내서 연결하기**를 누른 뒤 원형 패널을 클릭하거나 터치하세요.

| 기능 | 조작 |
| --- | --- |
| 블루투스 페어링 | 충전 케이스에서 이어버드 꺼내기 |
| 페어링 해제 · 재생 정지 | 양쪽 이어버드를 모두 넣고 뚜껑 닫기 |
| 재생 · 일시정지 / 전화 받기 · 끊기 | 왼쪽 또는 오른쪽 패널 두 번 터치 |
| 이전 곡 / 다음 곡 | 왼쪽 / 오른쪽 패널을 1.5초 길게 누르기 |
| 수신 거절 | 전화 수신 중 패널을 1.5초 길게 누르기 |
| 저지연 모드 켜기 · 끄기 | 오른쪽 패널 세 번 터치 |

**테스트 전화 걸기**로 수신 상황을 만들 수 있습니다. 블루투스 연결·통화·저지연 모드는 시뮬레이션이며, 데모 음악은 실제로 재생됩니다.

## GitHub Pages 게시

파일을 저장소 최상위에 올리고 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 선택하세요. 배포가 완료되면 **Visit site**에서 열 수 있습니다.

- `index.html`: 모든 화면과 동작이 포함된 웹사이트
- `.nojekyll`: 정적 파일 게시 설정
